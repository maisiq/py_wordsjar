# WordsJar

**Личный словарь английских слов с умной практикой**

Words Jar — веб-приложение для изучения английского словарного запаса.  
Пользователь собирает свою «банку» слов, регулярно проверяет знания и видит прогресс.

---

## Зачем это нужно

Большинство людей забывают новые слова уже через несколько дней.  
Words Jar решает эту проблему просто и понятно:

- Собираете слова, которые действительно хотите выучить
- Регулярно тренируетесь именно по ним
- Система сама показывает сначала те слова, которые знаете хуже всего
- Прогресс сохраняется и растёт со временем

Приложение подходит для самостоятельного изучения языка, корпоративного обучения сотрудников или как дополнительный инструмент в языковых школах.

---

## Что умеет приложение

### Для пользователя

| Возможность | Описание |
|-------------|----------|
| **Словарь** | Большая база английских слов с русскими переводами, транскрипцией и примерами использования |
| **Личная банка** | Можно добавлять любые слова из словаря в свою коллекцию |
| **Умная сортировка** | Слова в банке можно упорядочить по уровню знания («знаю хуже / знаю лучше») или по алфавиту |
| **Тренировки** | Тесты в двух направлениях: с английского на русский и наоборот |
| **Прогресс** | После каждого ответа система обновляет «рейтинг» слова — слабые слова появляются в тестах чаще |
| **Поиск** | Быстрый поиск по словам |

### Для администратора

- Добавление новых слов в общий словарь
- Управление пользователями (роли)

---

## Как это выглядит для пользователя

1. Регистрируется / входит в аккаунт  
2. Ищет нужные слова и добавляет их в свою банку  
3. Заходит в раздел «Тест» и тренируется  
4. Видит, какие слова уже хорошо знает, а какие ещё требуют внимания  

Всё просто, без лишних настроек и сложных механик.

### Основные сущности

- **Word** — английское слово, переводы (массив), транскрипция, примеры
- **User** — пользователь с ролью (`user` / `admin`)
- **UserWord** — связь пользователя и слова (рейтинг, количество попыток, дата последней попытки)
- **AuthSession** — сессии авторизации (refresh / revoked access tokens)

### API

- `/api/v1/words` — список и поиск слов
- `/api/v1/jar` — личная коллекция пользователя
- `/api/v1/exam` — получение слов для теста и проверка ответов
- `/api/v1/auth` — регистрация, логин, обновление токенов


### Запуск

Подробные инструкции по локальному запуску находятся в:

- `frontend/README.md` — фронтенд
- `backend/` — бэкенд (см. `pyproject.toml` и конфигурацию)

Для production-окружения предусмотрена сборка через Docker.
